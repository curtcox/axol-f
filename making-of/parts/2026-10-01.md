The upload script is written and committed as 2c046ec, after the films script (adb60b5). Both are ready to push. I only tested it with `--dry`, which never contacts YouTube. Nothing has been uploaded or signed in.

**On the faster Mac:**

1. Make the final film:

2. Sign in once. This needs a Google Cloud project with the YouTube Data API turned on and a "Desktop app" OAuth client, whose JSON file you download. The script saves the sign-in in that Mac's Keychain.
   ```bash
   node i18n/tools/youtube_upload.mjs --login --client=PATH_TO_CLIENT_JSON
   ```
3. Upload:
   ```bash
   node i18n/tools/youtube_upload.mjs --lang=es
   ```

**What the upload does:**
- It uploads the film with its title, description, tags, thumbnail and subtitles.
- It refuses a draft.
- If interrupted, running the same command again picks up where it stopped.
- It writes the video's ID into `i18n/es/site.yaml`, so the Spanish site embeds the film once you commit and push that file.

**One catch:** Google keeps any API upload private until it has audited your Cloud project, and it can't be made public in YouTube Studio. Until then, upload the film by hand in Studio and run this to fill in everything else:
```bash
node i18n/tools/youtube_upload.mjs --lang=es --video=VIDEO_ID
```
